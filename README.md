# nappio-dashboard

Admin dashboard for Nappio service

## Development

```sh
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Type check
npm run check
```

## Features

- **Deliveries View**: View and manage customer delivery information at `/deliveries`
- **Responsive Design**: Mobile-first design with responsive grid layout
- **API Integration**: Fetches delivery data from `/api/v1/admin/deliveries`
